# R5DGS: Semantic-Aware 4D Gaussian Splatting with Rigid Body Constraints for Efficient Dynamic Scene Reconstruction

**Авторы:** Denis Gridusov, Maxim Popov, Sergey Kolyubin (BE2R Lab, ITMO University)
**Площадка:** ECCV 2026 Workshop on Open-World 3D Scene Understanding and Representations; arXiv:2605.25909
**Ссылки:** https://arxiv.org/abs/2605.25909 · https://github.com/be2rlab/r5dgs

---

## 1. Задача

Эффективная 4D-реконструкция динамических сцен с сохранением физической правдоподобности экстраполяции и возможностью object-level семантического взаимодействия.

## 2. Метод

R5DGS расширяет физически-обоснованный 4D Gaussian Splatting (на базе TRACE) за счёт двух ключевых механизмов:

### 2.1. Identity Encoding

Компактные 16-мерные векторы, позволяющие группировать гауссианы в объекты без 3D-аннотаций. Это даёт семантическую организацию сцены на уровне объектов, а не частиц.

### 2.2. Rigid-body constraint при экстраполяции

Динамика вычисляется только для **репрезентативных гауссианов** (9–12 на объект). Движение остальных гауссианов propagated через относительные трансформации. Это сохраняет межточечные расстояния внутри объекта → физическая правдоподобность.

### 2.3. CLIP-lookup

Offline таблица для open-vocabulary запросов по тексту.

## 3. Результаты

- **+11 FPS** при экстраполяции по сравнению с TRACE;
- сложность инференса снижена с **O(N)** до **O(K)**, где K — число объектов;
- сохранение физической правдоподобности траекторий;
- open-vocabulary запросы без дополнительного обучения.

## 4. Ограничения

- Работает при **K < ~40 объектов**; при большем числе мелких объектов преимущество нивелируется.
- Не тестировалось на длинных последовательностях.
- Зависимость от качества предобученной CLIP-модели.

## 5. Значение для анализа

Самая свежая работа самого Колюбина по выбранной теме. Явно формулирует преодоление двух ограничений предыдущих подходов: вычислительной неэффективности per-particle динамики (TRACE) и отсутствия семантической согласованности.

## 6. Что взять для гипотезы

- Механизм rigid-body propagation на уровне объектов — основа proposed подхода.
- Ограничение K < 40 — точка роста для гипотезы (многоуровневая группировка).
- Identity Encoding — пример того, как семантика может быть встроена без аннотаций.
